# One Line, One Minute: The Vending Machine Pickup Line Contest

## The entry

> I only take exact change, but for you I'll take a chance — press B4 and see what drops.

## How it works

`main.py` writes the line above, unchanged, to `/output/entry.txt`. No network, no randomness, no dependencies — just one hard-coded string.
